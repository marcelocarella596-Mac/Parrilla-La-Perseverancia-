# Manual Administrador / Super Admin - borrador v0.1

1. Crear local desde Dashboard Master.
2. Activar módulos.
3. Crear usuarios con Firebase Functions `adminCreateUser`.
4. Asignar rol y local.
5. Generar QR.
6. Cargar menú inicial.
7. Ejecutar pruebas de comanda mixta, caja y cierre Z.
8. Auditar eventos desde `parrillaOS/audit`.
